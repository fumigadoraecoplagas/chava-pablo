# LATAM Code Factory

Landing page profesional para **LATAM Code Factory**, consultora de desarrollo de software, automatizaciones y soluciones de IA para pequenas y medianas empresas en Latinoamerica.

**Sitio en vivo:** https://latamcodefactory.web.app

## Estructura del proyecto

```
├── index.html          # Landing page principal (14 secciones)
├── styles.css          # Estilos (tema oscuro, glassmorphism, animaciones)
├── app.js              # Interactividad (particulas, filtros, scroll reveal)
├── og-image.png        # Imagen de preview para WhatsApp/redes sociales
├── firebase.json       # Configuracion de Firebase Hosting
├── apps/               # Apps gratuitas
│   ├── calculadora-aguinaldo.html     # Aguinaldo Costa Rica
│   ├── calculadora-aguinaldo-mx.html  # Aguinaldo Mexico
│   └── calculadora-co2.html           # Emisiones CO2 vehicular
└── demos/              # Mockups de portafolio (12 proyectos)
    ├── erpone.html

    └── fittrack.html
```

## Tech Stack

- HTML / CSS / JavaScript (vanilla, sin frameworks)
- Firebase Hosting
- Font Awesome icons
- DM Sans (Google Fonts)
